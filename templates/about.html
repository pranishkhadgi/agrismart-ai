About AgriSmart AI

A machine learning-powered crop recommendation system built as a BCA Final Year Project.

🎯 Project objective

AgriSmart AI helps farmers and agricultural officers make data-driven decisions about which crops to grow. By entering soil nutrients and climate conditions, the system recommends the most suitable crop, estimates expected yield, and identifies the farming zone — all powered by machine learning algorithms trained on real agricultural data.

🤖 The 3 AI algorithms

🌲

Random Forest — Crop Recommendation

An ensemble learning method that builds 100 decision trees during training. Each tree votes on the best crop, and the majority vote wins. This approach reduces overfitting and achieves ~99% accuracy on the crop recommendation dataset. It takes 7 inputs: N, P, K, temperature, humidity, pH, and rainfall.

📈

Linear Regression — Yield Prediction

Finds the best-fit linear relationship between soil/climate features and expected crop yield in kg/hectare. The model is trained on a derived yield score based on N, P, K, and rainfall values. Output gives farmers a quantitative estimate of how much they can expect to harvest per hectare.

🗺️

K-Means Clustering — Farming Zone

An unsupervised learning algorithm that groups data points into K clusters based on similarity. We use K=4 clusters, determined using the Elbow Method. Input features are normalized using StandardScaler before clustering to ensure no single feature dominates due to scale differences. Each cluster represents a distinct farming zone with similar agro-climatic characteristics.

📊 Dataset

The system is trained on the Crop Recommendation Dataset from Kaggle, containing 2,200 samples across 22 crop types with 7 features each. The dataset covers crops commonly grown in South Asian agricultural regions, making it relevant to the Nepali farming context.

Limitations: The yield prediction uses a derived yield score rather than real yield data, as the primary dataset does not include actual yield measurements. In a production system, this would be replaced with real district-level yield data from Nepal's Ministry of Agriculture and Livestock Development (MoALD).
